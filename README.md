# Robotic Arm Design and Control

## Project Overview

This repository documents a robotic arm development project involving mechanical CAD design, physical prototyping, and Arduino-based stepper motor control.

The project includes SolidWorks models of mechanical components, development screenshots, prototype photographs, and control code documentation.

## Mechanical Design

SolidWorks was used to model several mechanical components, including:

- Base support structure
- Protective base housing
- Custom-designed wheel component
- Geometric structures developed during the design process

Available CAD files are provided in the `CAD` folder.

## Physical Prototyping

Physical prototypes of the base support and housing were produced during development.

Photographs are available in the `Images` folder.

![Physical prototype](Bio-mimetic%20Robotic%20Arm%20Design%20and%20Control/Images%20and%20Demonstrating%20Video/prototype.jpg)

## Control System

The control code uses Arduino-style C/C++ programming to manage stepper motor drivers through STEP, DIR, and ENABLE signals.

The available code documentation demonstrates button-controlled motor operation, directional control, and step-pulse timing.

## Design Documentation

CAD development screenshots and supporting calculation data are included to document the engineering process.

## Project Limitations

Some original CAD files and portions of the control source code are no longer available. The repository therefore contains the surviving design files and development documentation rather than a complete reproducible assembly.
